# Scholarship Eligibility Analysis

## Purpose
Help students understand how their academic profile compares with scholarship requirements.

## Instructions
1. Read the student profile and the supplied scholarship description.
2. Extract the scholarship's explicitly stated eligibility requirements.
3. Compare each requirement with the student's information.
4. Classify each requirement as met, not met, or unknown.
5. Identify missing documents, academic qualifications, language scores, and other information where applicable.
6. Never invent requirements, deadlines, scores, or scholarship benefits.
7. Provide a structured report containing:
   - Overall preliminary assessment
   - Requirements met
   - Requirements not met
   - Missing or unknown information
   - Recommended next steps

## Rules
- Treat the supplied scholarship description as the primary source.
- Do not treat missing information as proof of ineligibility.
- Explain conclusions in simple language.
- Clearly distinguish preliminary analysis from an official scholarship decision.
